v1.0.82 新機能追加・UX 強化アップデート 2026-02-21
新機能 (New Features)
  • 📌
    ピン留めメッセージ一覧パネル スレッドヘッダーのボタンから、現在のスレッド内のピン留め済みメッセージをモーダルで一覧表示。各メッセージへのジャンプ・ピン解除も可能。グループスレッドにも対応。
  • 🌐
    オンラインユーザーリスト スレッドブラウザのサイドバー下部に、現在オンラインの他ユーザーを一覧表示。ステータス順（連絡可能 → 取込中 → 応答不可 → 退席中）でソート。15秒おきに自動更新。クリックでプロフィール表示。折りたたみ可能。
  • 🔴
    DM未読バッジ サイドバーの「DM」タブに未読メッセージ数の赤いバッジを表示。10秒ごとに自動更新。99件超は「99+」と表示。
  • ⌨️
    キーボードショートカット Esc リプライキャンセル / 検索結果を閉じる / モーダルを閉じる
    / 入力欄外から検索フォームにフォーカス
    Alt+P ピン留め一覧を開く
    Alt+Shift+? ショートカット一覧を表示
  • 🔍
    詳細検索フィルター（添付・日付範囲） 検索バーに詳細フィルターボタンを追加。「添付ファイルあり」チェックボックスと日付範囲（開始日・終了日）でメッセージを絞り込み可能。
  • 🔔
    ミュート機能（スレッド / DM / グループ） チャットヘッダーのベルボタンから、スレッド・DM・グループチャットごとに通知をミュート。キーワードが一致する場合はミュートを無視してプッシュ通知を届ける仕様。
バックエンド API 追加
  • ⚙️
    get_pinned_messages — スレッド・グループのピン留めメッセージ一覧を取得
  • ⚙️
    get_online_users — ステータス順にオンラインユーザー一覧を最大50件取得
  • ⚙️
    get_unread_dm_counts — 送信者別・合計の未読DM件数を返す
  • ⚙️
    toggle_mute / get_mute_statuses — ミュート設定の保存・取得
  • ⚙️
    search_messages 拡張 — has_attachment・date_from・date_to パラメータを追加
  • ⚙️
    update_notification_keywords — キーワード通知の保存 API
削除 (Removed)
  • 🗑️
    add_notif_col.php を削除 notification_keywords カラムの追加は index.php の DB スキーマ初期化で自動処理されるため、1回限りのマイグレーションスクリプトを削除。
