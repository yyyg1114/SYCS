v1.2.8 エラーハンドリング基盤の新設とロギングシステムの実装 2026-03-05
新機能 (New Features)
  • 🏗️
    バックエンドエラーハンドリング基盤の整備 (ErrorHandler.php) SecurityException、ValidationException、DatabaseException などの型付き例外クラスと、 JSON 形式の統一エラーレスポンスを生成する ErrorResponse クラスを新設。 エラー原因の種別を明確にし、適切なメッセージをユーザーに返せる堅牢な基盤を構築しました。
  • 📋
    サーバーサイドロガーの実装 (Logger.php) DEBUG〜CRITICAL の5段階ログレベルをサポートする Logger クラスを新設。 ログレベルごとに logs/ 配下の個別ファイルへ出力し、問題発生時の追跡とデバッグを容易にします。
  • 🔌
    フロントエンドAPIクライアントの整備 (errorHandler.js) タイムアウト検知、ネットワークエラー自動判定、CSRF トークン自動付与、構造化エラーメッセージ表示を備えた APIClient クラスを新設。フロントエンドのAPI通信品質と信頼性を向上させました。

v1.2.1 通知機能の正常化・操作権限の拡張・利便性の向上 2026-03-01
新機能 & 改善 (New Features & Improvements)
  • 🔔
    通知機能の完全な正常化 ブラウザ通知が Socket.io のイベントと連動し、別のスレッドを開いている際やウィンドウが非フォーカス時でも確実に届くよう改善。 プッシュ通知 (Web Push) の不具合（環境変数の欠落等）を解消し、バックエンドからの送信処理を全メッセージタイプに拡張。

  • 🏠
    Generalスレッドの機能制限緩和 誤消去防止のため編集・削除は制限しつつも、メッセージ検索やビデオ通話、添付ファイルギャラリーなどの便利機能を有効化しました。
v1.2.0 ミーティング機能の大幅強化・メールログ・バグ修正 2026-03-01

  • 🐛
    フレンド検索が動作しない問題の修正 searchUsers() 関数内の JavaScript テンプレートリテラルが誤って複数行に分割されており、 API の URL・表示名・確認ダイアログの文字列がすべて壊れていた問題を修正。 フレンド申請・ユーザー検索が正常に動作するようになりました。

v1.1.0 PWA（Progressive Web App）対応 2026-02-21
新機能 (New Features)
  • 📱
    PWA（Progressive Web App）化 SYCSをホーム画面に追加して、ネイティブアプリのように利用可能に。スタンドアロンモードでの表示に対応。
  • 📦
    Web App Manifest (manifest.json) を新規作成 アプリ名・テーマカラー（#6366f1）・アイコン・表示モード（standalone）・ショートカット等を定義。iOS / Android / デスクトップでのインストールに対応。
  • ⚡
    Service Worker を大幅拡張 既存のプッシュ通知専用 sw.js を、フルPWA対応のService Workerに拡張。静的アセットの事前キャッシュ、キャッシュ戦略の使い分け（API→キャッシュなし / 静的→キャッシュファースト / HTML→ネットワークファースト）、古いキャッシュの自動クリーンアップを実装。
  • 📡
    オフラインフォールバックページ インターネット接続がない場合に、専用のオフラインページを表示。再接続ボタンでリトライ可能。
  • 🔔
    インストールバナー 初回訪問時に3秒後にスライドアップアニメーションでPWAインストールバナーを表示。「インストール」ボタンで即座にホーム画面へ追加可能。一度閉じたバナーはlocalStorageで記憶。
  • ⚠️
    オフラインインジケーター ネットワーク切断時に画面上部に赤いバーで「オフラインです」と警告表示。オンライン復帰時は自動で非表示。
改善 (Improvements)
  • 🏷️
    全ページにPWAメタタグを追加 index.php・login.php に theme-color、apple-mobile-web-app-capable、apple-mobile-web-app-status-bar-style、manifest リンク等のPWA関連メタタグを追加。iOS Safari / Edge / Chrome で最適に表示。
  • 🔧
    Service Worker登録の統合 プッシュ通知の initPush() 内で行っていたSW登録を navigator.serviceWorker.ready に変更し、グローバルなPWA登録と統合。重複登録を防止。1時間おきにSWの更新チェックを実施。
  • 📐
    Safe Area対応 スタンドアロンモード時に env(safe-area-inset-*) を適用し、ノッチ付きデバイスや角丸ディスプレイでのレイアウト崩れを防止。viewport-fit=cover を追加。
  • 🔔
    プッシュ通知のアクション追加 プッシュ通知に「開く」「閉じる」のアクションボタンとバイブレーションパターンを追加。通知クリック時に既存ウィンドウにフォーカスする動作を改善。
